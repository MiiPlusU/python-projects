# 🎨 Hirst Painting Project

A Python turtle graphics project that generates algorithmic art inspired by Damien Hirst's famous spot paintings.

## 🎯 Project Overview

Create beautiful, colorful dot paintings using Python's turtle graphics module. Generate random color patterns and geometric arrangements reminiscent of contemporary art.

## ✨ Features

- **Turtle Graphics:** Visual programming with Python's turtle module
- **Random Color Generation:** Dynamic color palette creation
- **Geometric Patterns:** Systematic dot arrangement and spacing
- **Art Generation:** Algorithmic approach to visual art creation
- **Customizable Parameters:** Adjustable grid sizes, dot sizes, and spacing
- **Color Theory Application:** Aesthetic color combination algorithms

## 🚀 How to Run

```bash
# Navigate to the Hirst Painting Project directory
cd "Hirst Painting Project"

# Run the art generator
python main.py
```

## 🎨 About Damien Hirst

Damien Hirst is a British contemporary artist known for his "Spot Paintings" series - perfectly circular dots of color arranged in grids. This project recreates that aesthetic using algorithmic generation.
