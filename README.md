# 🐍 Python Projects Portfolio

A comprehensive collection of Python projects showcasing various programming concepts, from beginner games to production-ready APIs with machine learning capabilities.

## 📁 Project Overview

### 🚀 **Production-Ready APIs**
- **[Artifactory Flask API](./artifactory-flask-api/)** - Production-style Flask API for JFrog Artifactory management with PostgreSQL logging
- **[Churn ML Flask API](./churn-ml-flask-api/)** - Machine learning API for customer churn prediction using scikit-learn

### 🎮 **Games & Interactive Projects**
- **[BlackJack Capstone Project](./BlackJack-Capstone-Project/)** - Classic card game implementation with ASCII art
- **[Quiz Game](./Quiz Game/)** - Object-oriented trivia game with question bank system
- **[Higher-Lower Game](./Higher-Lower Game/)** - Celebrity/entity comparison guessing game
- **[The Number Guessing Game](./The Number Guessing Game/)** - Interactive number guessing with difficulty levels

### ☕ **Simulation & Automation**
- **[Coffee Machine Project](./Coffee Machine Project/)** - Coffee vending machine simulator with resource management
- **[ISS Overhead Notifier Project](./ISS Overhead Notifier Project/)** - Real-time ISS tracking and notification system
- **[Mail Merge Project Start](./Mail Merge Project Start/)** - Automated letter generation with personalization

### 🎨 **Creative & Graphics**
- **[Hirst Painting Project](./Hirst Painting Project/)** - Algorithmic art generator inspired by Damien Hirst's spot paintings
- **[Mini Projects](./Mini Projects/)** - Collection of smaller projects including Turtle graphics and API integrations
- **[Challenges](./Challenges/)** - Various coding challenges and exercises

### 🌐 **Web Development**
- **[Landing Page](./Landing Page/)** - Static webpage project with HTML/CSS

## 🛠️ **Technologies Used**

- **Backend:** Flask, SQLAlchemy, PostgreSQL
- **Machine Learning:** scikit-learn, pandas, numpy
- **Testing:** pytest, unittest
- **Graphics:** turtle, PIL
- **APIs:** requests, RESTful services
- **Data Processing:** pandas, CSV handling
- **Authentication:** Bearer tokens, environment variables

## 🚀 **Getting Started**

Each project contains its own README with specific setup instructions. General setup:

```bash
# Clone the repository
git clone https://github.com/MiiPlusU/python-projects.git
cd python-projects

# Navigate to any project
cd "project-name"

# Install dependencies (if requirements.txt exists)
pip install -r requirements.txt

# Run the main file
python main.py  # or specific entry point
```
